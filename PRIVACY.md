# Privacy Policy

Last updated: 2026-09-16

Frappe Config Pack is an open-source Frappe application for packaging,
reviewing, and deploying configuration between Frappe sites.

## Data handled by the app

The app works with configuration records that an administrator selects, such as
custom fields, workflows, property setters, roles, scripts, reports, and print
formats. Packages, deployment plans, snapshots, and installation history are
stored in the Frappe site where the app is installed.

## No telemetry or external data transfer

Frappe Config Pack does not include analytics, tracking, advertising, or
telemetry. It does not send configuration data to a service operated by the
project maintainers. Administrators control where package files are exported
and uploaded.

## Credentials and sensitive values

The application is designed to avoid serializing sensitive notification
credentials, including Slack webhook URLs, into configuration packages.
Administrators remain responsible for reviewing their selected resources and
protecting generated package files.

## Your responsibilities

Use the app only with sites and configuration data you are authorized to
manage. Keep exported packages in a secure location and follow your
organization's data-retention and access-control policies.

## Support and contact

For security concerns, see [SECURITY.md](SECURITY.md). For product questions or
technical support, open an issue in the project's GitHub repository.
